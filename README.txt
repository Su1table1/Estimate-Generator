Estimate Generator
Version 1.1.0

========================================================
OVERVIEW
========================================================

Estimate Generator is a Windows desktop application designed
to quickly generate formatted estimates using customizable
templates and dynamic fields.

Templates are fully editable and support reusable placeholders
for fast estimate generation.

========================================================
FEATURES
========================================================

- Dynamic estimate templates
- Real-time preview generation
- Automatic field detection
- Template editor
- Copy to clipboard support
- Automatic template syncing
- Responsive interface
- Custom installer
- Portable template system

========================================================
INSTALLATION
========================================================

Run the installer and follow the setup wizard.

Optional shortcuts:
- Desktop shortcut
- Start Menu shortcut

========================================================
HOW TO USE
========================================================

1. Select a template from the dropdown menu.
2. Fill in all generated fields.
3. Review the generated preview.
4. Click "Copy to Clipboard".
5. Paste the estimate where needed.

========================================================
CREATING TEMPLATES
========================================================

Open the Template Editor using the "Edit Templates" button.

Templates support placeholders using the following format:

%%FIELD_NAME%%

Example:

Customer: %%CUSTOMER_NAME%%
Price: %%TOTAL_PRICE%%

Fields are automatically detected and generated.

========================================================
TEMPLATE STORAGE
========================================================

Templates are stored inside:

Templates\

The application automatically creates:
- Templates folder
- Templates.json

Manually added .txt templates are automatically detected
and added to the template system.

========================================================
UNINSTALL INFORMATION
========================================================

Uninstalling the application will permanently remove:
- templates
- Templates.json
- application settings

Backup your Templates folder before uninstalling if needed.
